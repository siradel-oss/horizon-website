Horizon peut streamer des [données vectorielles depuis de nombreux formats et protocoles](/doc/vector_data_layers?lang=en).
Les données vectorielles peuvent également être fournies directement depuis l'application ou
encore résider en mémoire pour les applications interactives.

Plusieurs sources d'attributs peuvent être combinées pour enrichir des données open-source avec des attributs métier.

Le [langage de script de style](/doc/styling_api?lang=en) intégré facilite la personnalisation approfondie de l'affichage
de vos données et permet de mettre en valeur des informations clés sur vos cartes.

De multiples représentations vectorielles peuvent être combinées pour créer des scènes riches.
