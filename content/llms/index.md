# Horizon

> Horizon is a 3D engine for geospatial data visualization. It is built to be multi-platform (Native and Web through WebAssembly) and ships API bindings for C++ and TypeScript.

The engine supports imagery rasters, DTM rasters, vector data, glTF models, 3D Tiles, has many interactive tools & features, and extensive customization options.
